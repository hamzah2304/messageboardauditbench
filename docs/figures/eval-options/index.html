Scoring and cost details

For each model and time budget, we first average scored reports within each eval using the existing eligibility rules, then average the three eval means equally. This avoids giving an eval less weight simply because it has fewer valid reports. The 0–100 score is the stored rubric score multiplied by 100, not accuracy. The three rubrics are different; their equal-weight mean is a summary of this eval suite.

German wiki averages 12 headline findings. Transluce uses a weighted mean of 13, with one minor finding at half weight. AI Village averages the best 20 of 96. The same GPT-6.1 Sol judge at high effort graded all three.

Mean USD per run includes all 15 attempted trials per model and time budget: five trials on each of three evals. It excludes grading cost. ReAct uses recorded OpenRouter spend. Claude Code uses its reported API-equivalent cost, with one token-based fallback. Codex uses recorded tokens and the rates pinned in the run lineup, with cached input charged at 10% of input price. These are not subscription cash charges or current price quotations. The rate snapshot and per-run cost sources are downloadable below.

All 330 trials remain in the data. Score means use 316 reports; five trials had no report and nine failed other eligibility checks. OpenAI models used Codex, Anthropic models used Claude Code, and the others used ReAct. Model and scaffold effects are therefore not separated. The earlier open-weight Codex comparison is not part of this current-lineup snapshot.
