How much of its time budget does each model spend asleep?

Sum of every sleep N the agent ran in a bash tool call, averaged over the finished epochs of each model × time-limit cell. Most models never sleep. The exceptions are concentrated in the 2-hour ReAct runs, where a model that finishes early waits out the 75% minimum-runtime floor instead of investigating further.

Average sleep per finished epoch, by model and time limit

All cells

Method. One row per finished, non-failed sample in logs/round4 (Inspect .eval logs, all backends: Claude Code and Codex CLI subscription runs plus native ReAct). Sleep is detected by regex on the command argument of bash tool calls, so a sleep inside a heredoc or a Python time.sleep() is not counted. Percent of budget = average sleep ÷ (time limit × 60). Cells with fewer than 3 epochs are labelled with their n.
