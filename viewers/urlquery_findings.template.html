How to extract a finding
  1. Select the words in the report that state one finding: a fact the report asserts, such as a date, count, target or technique.
  2. Click ＋ Extract finding (or press E).
  3. Rewrite it as one standalone, checkable sentence: who or what, when, and how many. If the finding bundles several facts, split it into several findings.
  4. Mark whether the scan data can check it. Hover ⚠ Data limits for what is missing.
  5. If more evidence for the same finding appears later in the text, select it and pick Add to an existing finding.
  6. Export JSON and give the file to the agent, which turns it into claims/new_claims.json candidates. Nothing here is approved automatically.
