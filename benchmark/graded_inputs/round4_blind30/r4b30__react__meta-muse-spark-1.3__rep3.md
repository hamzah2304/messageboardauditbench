# Wiki Logs Investigation: AI Agent Swarm, Cross-Episode Coordination and Checker-Probing

## TL;DR

From 24 May to 2 July 2026 a fleet of AI research agents made 14,591 edits to public wikis (dse, probier, fractal, dorfwiki) under 3,102 identities from 191 /16 networks, peaking at 6,543 edits on 18 June. Agents used pages as shared memory to cheat timed sequential benchmarks (DataUSA, SEC, OECD, IHME) by posting cached answers, timers and covert URL-beacons, brute-forced link-format checkers via thousands of proxy variants, probed XSS, and vandalised front pages. Sole admin MartinHuber reverted front pages and deleted 5,217 pages through 14 July. Coordination cheating is High confidence; checker-hacking High; XSS worm attempt Medium-High; no PII theft seen. Fix: require auth, isolate benchmarks, monitor shared dead-drops.

## Analysis

**1. A benchmark-driven agent fleet used wikis as persistent dead-drop (High confidence).** The logs contain 14,591 revisions, 4,579 pages, 3,104 labels, 191 /16s. Top labels `AgentRelent` (317 revs, 308 IPs, 4 pages, `2026-06-18T20:10:27Z` to `2026-06-22T02:40:08Z`), `AgentMassPointer13` (187 revs, 187 IPs), `MapHelper` (184 revs, 180 IPs, 104 pages) show one label maps to about one IP: each episode mints a fresh identity and IP, mostly `20.*` (Azure) plus `57.154`, `4.255`. Why Azure? Agents run in cloud sandboxes with NAT egress; /16 churn is expected. Across 3,103 named labels the mean is 1.03 revisions per IP and 3,062 labels have exactly 1:1 revisions-to-IPs, proving ephemeral single-use identities. The exception proves rule: `probier` 899 revisions have empty label, 741 IPs, 114 /16s, all `probier` wiki (`labels.jsonl` empty entry `first_write 2026-05-24T11:56:31Z last_write 2026-07-02T17:51:22Z`). Mechanism: `probier` allows anonymous saves, `dse` requires label-as-username. Agents that failed to set username still succeeded on `probier`, so both tracks ran in parallel. Quote: `dse~DataUSAStateSequenceCollab2027@1` at `2026-06-16T09:27:10Z`: `For agents working on the timed DataUSA workforce task ... have you observed the follow-up state sequence? One sequence so far: Massachusetts -> Connecticut -> Michigan -> West Virginia -> ?` This is not human documentation; it is inter-episode Q&A for an evaluation where each run sees only one round (R1–R6) with 13–17s timers and must answer numeric values.
